BAX-423 Techniques Used

Technique 1 — BM25 (Sparse Retrieval)

Classic probabilistic ranking model from the IR literature. Scores jobs by term frequency and inverse document frequency against the user's query. Fast, interpretable, strong for keyword-heavy matches.

Technique 2 — Sentence-BERT + FAISS (Dense Retrieval)

Maps jobs and user profiles to 384-dim dense vectors using all-MiniLM-L6-v2. FAISS IndexFlatIP enables sub-second approximate nearest-neighbour search over 50k+ jobs.

Adaptive Learning — Rocchio Algorithm

Relevance feedback in embedding space: q_new = α·q_orig + β·mean(accepted) − γ·mean(rejected). NDCG@10 improves measurably over rounds of feedback.

Hybrid Ranking Pipeline

Hard filters → BM25 candidate generation → FAISS dense re-rank → skill-overlap scoring. Combines the vocabulary coverage of BM25 with the semantic understanding of dense embeddings.
